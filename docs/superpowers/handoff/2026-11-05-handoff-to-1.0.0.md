## 5. Next step: finish D2 (agentgateway)

**Headline finding, verified twice** (from the source at tag v1.6.0 and by running the binary): agentgateway v1.6.0 CAN enforce tool arguments, which contradicts the plan's assumption.
- The documented `mcp.tool.arguments` is empty at authorization time (issue #2069).
- But `streamablehttp.rs:155-158` keeps the raw body in the authorization context, so CEL `json(request.body).params.arguments.<x>` works.
- The D2 layer therefore renders argument and scope rules. The owner must know this: the results page must not claim "agentgateway can't check arguments".

**Required fixes from the D2 review.** For each one, add a binary-backed test case first, in `bench/tests/test_agentgateway_layer.py::test_rendered_rules_match_atp_semantics_on_binary`.
1. **IMPORTANT (argument_max / argument_min).** CEL `double("-inf")` passes `<= 100`, while ATP denies non-finite values (`_to_decimal`). Require finite values, and check NaN as well.
2. **IMPORTANT (resource scope).** `_scope_condition` must apply ATP's resource-id validity rule, `RESOURCE_PATTERN` `[^*\x00-\x1f\x7f]{1,255}` in `packages/core/src/atp_core/resources.py:13`: non-empty, at most 255 characters, no `*`, no control characters. It must apply in every branch, including `*` and `<type>:*`.
3. **Minor (string length).** CEL `size(string)` counts bytes, ATP counts code points. Match ATP if CEL can (for example with a regex); otherwise list it as an approximation.
4. **Minor (numeric strings).** ATP's `Decimal` accepts `" 50"` and `"1_000"`, and integers above 2^53 lose precision in CEL doubles. Document these in the doc's approximations, and match ATP where that is cheap.
5. **Minor (non-ASCII literals).** Use `json.dumps(..., ensure_ascii=False)` in `_lit` / `_member`, and test a non-BMP value on the binary.
6. **Doc** (`bench/competitors/agentgateway.md`):
   - Say that body access inside mcpAuthorization is shown by the source, not by the MCP authorization docs, so it may change.
   - Record what was tested: duplicate JSON keys (CEL and the upstream both use the last value) and JSON-RPC batch (rejected with 400).
   - Make the mapping table exact.

A partial, unverified attempt at these fixes is in `docs/superpowers/handoff/2026-11-05-d2-fix-partial.patch`. It is optional: apply it with `git apply`, then verify it, or ignore it. Delete the patch file once D2 is done.

Commit message: `bench: agentgateway rules match ATP on infinities, resource ids and unicode`.

## 7. Known open items and deferred minors (from reviews)

- **C1 `atp migrate`:**
  - A file with mixed line endings gets CRLF on the inserted line.
  - Duplicate top-level `version:` keys leave the stale earlier line in place.
- **C3 approvals:**
  - Removing an approver from `ATP_APPROVER_ROLES` does not revoke an approval they already gave (24 hours at most).
  - `APPROVAL_INVALID` covers both "bad duration" and "bad signature". Split it before the freeze if you want it split.
- **C4 budgets:**
  - There is no CLI for an operator to settle or release a held reservation; it is HTTP / store only.
  - Only an argument named exactly `amount` is budgeted (this is documented).
- **C5 signed roots:**
  - Two processes migrating the same old home at the same moment can each generate a key.
  - `atp trace list` on a 0.3.2 home migrates the grant key but not the roots; roots migrate on the first `ensure()`, e.g. `atp mcp wrap`.
  - `atp approve` on an unmigrated home is untested.
- **C9:** `atp policy impact` exits 0 when decisions change; it exits 1 only with `--fail-on-widen` on a widening. `stability.md` documents exactly this.
- **D1 fetcher:** cached binaries are trusted by their stamp file and not re-hashed.
