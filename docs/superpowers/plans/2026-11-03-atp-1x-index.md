# ATP 1.x plan index

**Spec:** `docs/superpowers/specs/2026-11-03-atp-1x-design.md` (approved 2026-11-03).

The spec covers several independent subsystems, so it is split into one plan per subsystem. Each plan ships working, tested software on its own branch, `release/v1/<ticket>-<slug>`, and goes out as its own PR series. Merges and releases need owner approval.
