# v0.3.0 release plan

Justification for a minor (feature) release: new CLI surface (`mcp init/wrap`,
`policy *`, `mutate`, `regression add`, `evidence`, `trace`), shadow mode,
declared policies, prefix scopes, Streamable HTTP upstream, single
distribution, and breaking changes listed in CHANGELOG "Changed". Version
bumped from 0.2.0 to 0.3.0 in every `pyproject.toml`, `package.json`,
`app.py`; the proxy reports `0.3.0`.

## Scope (done)

See CHANGELOG.md [0.3.0].

## Gate (must all pass before tagging)

The exact commands and their results are recorded in `verification.md`.

1. ruff check + format check; mypy --strict
2. pytest (full), incl. property tests, MCP e2e (stdio + HTTP), wrap e2e
3. opt-in third-party MCP e2e (`ATP_E2E_NPX=1`)
4. evals 8/8
5. demos A/B/C/D exit 0; sample suite exit 0 under v2 and 1 under v1
6. dashboard typecheck + build
7. `uv build`; `uvx --isolated --from dist/*.whl atp doctor`; `pipx`-equivalent
   install (`uv tool install dist/*.whl`); `uvx --from git+file://…`
8. pip-audit on the locked runtime set; SBOM generated
9. link check; secret/history scan; no private paths in tracked text
10. benchmark regenerated at the release commit
11. first-user test recorded

## Tag and publish (needs approval)

- `git tag v0.3.0`; create the GitHub repository; push `main` and tags;
  GitHub release from `v0.3.0-notes.md`; PyPI publication of
  `agent-trust-plane` (trusted publishing to be configured). None of this
  happens without the maintainer's explicit approval.
