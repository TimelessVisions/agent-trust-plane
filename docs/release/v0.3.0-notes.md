# Agent Trust Plane v0.3.0

**Put a real authorization boundary between your AI agent and its tools, and
turn every dangerous action into a regression test so it cannot silently
come back.**

Experimental. No users yet. Not independently audited. MIT.

## What is new

- **`atp mcp init -- <server command>` then `atp mcp wrap`**: discover an
  MCP server's tools, review the proposed capabilities, and serve a
  protected copy with the gateway running in-process from a local `.atp/`
  directory. No keys to copy, no services to run. Streamable HTTP upstreams
  via `--url`. Measured: 37 s from a cold clone to the first ALLOW and DENY
  on a real server.
- **Shadow mode** (`--mode shadow`): decisions are recorded as `WOULD_DENY`
  and forwarded, so you can build policy before enforcing. The mode is a
  gateway setting; a caller cannot request it; every trace says which mode
  it was.
- **Path scopes**: `path:/abs/dir/*` with `..`, separators and optional
  case folding normalised before matching. The traversal test on the
  reference filesystem server is denied by scope, not by luck.
- **Declared policy sets** (`.atp/policies.yaml`, eight rule kinds) beside
  the built-ins; the kernel policies always apply.
- **`atp policy explain`** (which constraint failed, both values, what
  would need to change — derived, not generated), **`diff`**, **`impact`**
  (which recorded actions flip; DENY→ALLOW first; `--fail-on-widen`),
  **`coverage`** (guarded vs unguarded dimensions, no score).
- **`atp mutate`**: perturb a recorded action along resource, identity,
  capability and arguments; authorize only; mutations outside the recorded
  authority must be denied or the command exits 1.
- **`atp regression add TRACE`** from the local store; **`atp evidence
  export/verify`** hash-checked bundles; **`atp trace list/show`**.
- **Property-based tests** (delegation monotonicity, scope-algebra
  soundness, decision determinism, stateful grant lifecycle) and an
  exhaustive grant state-machine check against a written spec. One bug
  found and fixed (a revoked-after-consumed grant lost its consumed state).
- **One distribution**: `agent-trust-plane` builds one wheel with the `atp`
  entrypoint; `uvx --from <wheel or git URL> atp` verified. Not on PyPI yet.
- Performance: one SQLite transaction per kernel operation (events and
  grant state commit atomically); the wrap path adds ~11 ms p50 to an MCP
  call with durable evidence.

## Breaking changes

Resource grammar and templates, `ToolMapping.resource_arguments` removed,
`atp mcp-init` → `atp mcp init`, `McpInterceptor` removed. Details in
CHANGELOG.

## Known limitations (unchanged headlines)

Only the mediated path is protected; the operator key is omnipotent; bearer
agent credentials; single-use grants do not imply exactly-once external
effects; the hash chain is recomputable by a DB writer; declared policies
are limit/equality rules; served transport is stdio only; no approval
workflow, budgets, rate limits or multi-instance deployment. Full lists:
`docs/security/threat-model.md`, `docs/security/security-review.md`.
